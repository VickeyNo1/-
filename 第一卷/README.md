## 使用边界

- 全书稳定规则只引用 `../设定文档/`，本目录只保存第一卷执行安排。
- 第一卷只使用当前案件需要的组织、能力和城市地点。
- 父亲死亡势力不参与本卷实验案，只在结案复盘中留下一个不足以锁定身份的交叉痕迹。
- 前几卷副本中不能使用现实异能或携带现实装备。
- 私人实验只能提高被副本捕获的概率和受训者的生还率，不能指定副本、固定组队、保证觉醒或选择能力类型。
- 规则类属于先天异能结构；失控崩溃只能放大周围捕获概率，不能制造或控制通道。第三次副本由科学家诱发主男主崩溃间接造成。
- 主男主卷末正式加入官方以自保、训练和管理失控风险为首要动机，不得写成突然产生献身使命。
- 第一卷不得揭露异世界完整起源、成功返回加深侵蚀、最早进入者状态和终局真实通道。
- 四份执行文档完成并经用户确认后，才能开始章节级拆分和正文。
