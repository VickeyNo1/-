# 《群梦余生》第一卷执行文档说明

本目录是第一卷的创作执行层，不是第二套世界观百科。全书稳定设定仍以 `../设定文档/` 为唯一权威来源；本目录只记录第一卷会实际使用的剧情边界、人物状态、案件副本链和连续性事实。

## 文档职责

1. `00-第一卷总纲.md`：管理本卷起点、终点、主题、主要矛盾、信息揭露边界和阶段节奏。
2. `01-人物与成长轨迹.md`：管理第一卷出场人物的等级、技能、关系、秘密、弧线和禁止写崩点。
3. `02-案件与副本链.md`：管理每个故事单元的现实案件、同频媒介、副本因果、现实证据和主线推进。
4. `03-线索伏笔与连续性台账.md`：管理谁知道什么、伏笔出现与回收、物品次数、伤亡、人情债和已经写入正文的事实。

## AI 接入顺序

讨论第一卷结构时：

1. 读取本文件。
2. 读取 `00-第一卷总纲.md`。
3. 根据任务读取人物、案件或连续性文档。
4. 只在涉及能力边界、管理员、现实势力或事故真相时，读取 `../设定文档/` 中对应专题文档。

撰写或修改具体章节时：

1. 读取 `00-第一卷总纲.md`。
2. 读取 `01-人物与成长轨迹.md` 中本章出场人物。
3. 读取 `02-案件与副本链.md` 中当前故事单元。
4. 读取 `03-线索伏笔与连续性台账.md` 的最新状态。
5. 读取当前章节前后各一章；需要能力细节时再查全书专题文档。

不要为写一章正文而默认读取十二位管理员全部档案。作者知道全部真相，不等于当前视角人物和读者应该知道。

## 状态标记

- **已确认**：可直接作为创作依据。
- **工作草案**：允许用于继续讨论和排布，不得写成不可逆正文事实。
- **待确认**：只记录问题或候选方向。
- **已发布事实**：已经公开给读者，修改必须按 `../设定文档/98-AI设定变更协议与日志.md` 处理。

## 维护原则

- 全书规则只在 `../设定文档/` 定义一次，本目录使用摘要和链接。
- 第一卷的动态状态只在本目录维护，不回填为全书普遍规则。
- 每完成或修改一章，必须同步更新连续性台账。
- 每发生整体设定变更，先更新全书权威文档，再执行影响分析和第一卷同步。
