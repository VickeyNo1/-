# 96-旧能力核心概念审计

状态：C级重构工作文件，不是新版异能体系权威正文。

本文件只负责从旧十二领域中提取仍有原创价值的底层概念。旧领域名仅用于定位历史材料，不代表新版继续保留该名称、人物、领域、技能组、等级或阵营。新版遵循“先提炼概念，再创造人物”的顺序，不从旧管理员名单中直接挑选保留者。

## 一、审计标准

一个概念只有同时满足以下条件，才值得进入新版候选库：

1. 能用一句话说明它操作的真实对象，而不只是列举几种招式。
2. 能从人物在异世界中维持自我的方式自然产生。
3. 可以发展出多种表现，但所有表现仍能从同一核心原理推导。
4. 与其他概念有清楚边界，不是换名后的同类精神控制、强化或攻击。
5. 能承担人物主题、案件解法或主线冲突，而不只提供战斗数值。

“保留”只表示保留底层思想，不表示保留旧人物或旧技能。“合并”表示该概念可成为其他核心原理的一种表现。“重构”表示题材有价值，但旧稿尚未形成足够统一的原理。“淘汰”表示不再为它设置独立能力源。

## 二、已经锁定的三项核心概念

### 程序

- **操作对象**：可执行的条件、步骤、循环与调用关系。
- **不可替代性**：它不改变物理定律，而是识别、编排和封装现实中本来能够完成的行动。
- **基本边界**：必须理解条件并具备执行基础；不能用一句代码凭空制造事实，也不能事后补写结果。
- **旧稿可回收材料**：条件分支、预置反应、循环与中断、行动封装、搜索与路径组织；“备份”只能作为待重新论证的高阶表现，不能自动继承。

### 概率

- **操作对象**：尚未确定事件的可能分布与权重。
- **不可替代性**：它既不写入执行规则，也不组织多个系统，只在真实存在的未来之间读取、偏转或作出承诺。
- **基本边界**：零概率不能变成非零；结果越重大、牵涉的独立意志越多，越难干预；固定终点不等于控制过程。
- **旧稿可回收材料**：分布、倾斜、坍缩与“必然”的终点锁定；具体强度和代价必须按新版规则重做。

### 系统

- **操作对象**：多个动态个体之间的连接、反馈、学习与整体涌现。
- **不可替代性**：它不精确指定单个动作或最终答案，而是改变各节点如何彼此影响，使整体产生单个节点不具备的新行为。
- **基本边界**：必须存在可观察的输入、输出、共同变量或真实反馈；系统规模越大，潜力越强，结果也越难被使用者精确控制。
- **旧稿可回收材料**：耦合、反馈、泛化和共享表征；“点化”涉及人格连续性，可作为候选极端表现，但不能默认保留。

三者的边界暂定为：**程序决定已知步骤如何执行，概率决定已有路径哪条实现，系统决定多条路径相互作用后是否产生新路径。**这不是固定克制链，也不意味着三者必须由旧人物或三名最早进入者分别承载。

## 四、当前结论

1. 程序、概率、系统已经正式进入新版核心概念库。
2. 关系回应、空间模型、身体图式、共振、记忆版本进入强候选区。
3. 疼痛与拒答保留主题价值，但必须重新抽象统一原理。
4. 凝视与情绪优先考虑合并，不再默认拥有独立承载者。
5. 旧人物姓名、管理员序号、三技能结构、九级成长、代行者质变和固定克制关系全部不随概念继承。

## 五、后续顺序

1. 逐项确认候选概念的去留与边界。
2. 确定最终需要多少种核心概念，以及哪些只作为个人表现存在。
3. 再决定最早进入者人数，并为每个人分配一种与其求生方式吻合的核心原理。
4. 最后重新创造姓名、身份、经历、立场、现实牵挂和结局。
