# 《群梦余生》设定文档目录说明

本目录是本小说项目的全书设定中枢，负责稳定世界规则、管理员、能力、角色底色、现实势力和全书阴谋。`../第一卷/` 是第一卷创作执行层，负责本卷边界、人物动态、案件副本和连续性。根目录《小说项目交接文档.md》保留为历史交接与讨论归档，不再作为持续更新的权威设定源。

发生冲突时，按以下优先级处理：

1. 已发布正文中的明确事实。
2. 本目录对应专题文档中的已确认设定。
3. `99-待定问题与决策记录.md` 中的已确认决策。
4. `../第一卷/` 中的本卷执行安排。
5. 工作草案、待确认方案和历史交接档。

若已发布正文与权威设定冲突，不得直接覆盖，必须按 `98-AI设定变更协议与日志.md` 处理。

## 家里电脑 Codex 接入顺序

新的 Codex/agent 接手全书设定任务时，请按顺序读取：

1. `设定文档/README.md`
2. `设定文档/00-项目总览.md`
3. `设定文档/99-待定问题与决策记录.md`
4. 根据任务读取对应文档：
   - 讨论世界观：读 `01-世界观圣经.md`
   - 讨论领域技能、限制、成长和代行者质变：读 `02-领域与能力体系.md`
   - 讨论管理员背景、立场、关系、记忆考验和神降：读 `02-管理员档案.md`
   - 完整设计某位管理员及其领域：两份 `02` 文档一起读
   - 讨论双男主、配角：读 `03-角色档案.md`
   - 讨论现实势力：读 `04-现实势力.md`
   - 讨论事故阴谋、三位特别管理员立场与终局：读 `05-阴谋与事故线.md`
   - 讨论管理员敌对关系、领域克制与阶段强度排名：读 `06-管理员关系与领域克制排名.md`
5. 处理第一卷时，转读 `../第一卷/README.md`，不要默认读取全部管理员档案
6. 只有追溯历史讨论时，才读取根目录 `小说项目交接文档.md`

## 第一卷创作接入顺序

讨论第一卷总纲、副本或章节时，优先读取：

1. `../第一卷/README.md`
2. `../第一卷/00-第一卷总纲.md`
3. 当前任务对应的人物、案件或连续性文档
4. 只在需要核对规则边界时，回查本目录对应专题文档

发生整体设定变更时，先读 `98-AI设定变更协议与日志.md`。AI必须先提交影响分析，等用户确认后再批量修改。

## 后续维护原则

- 已确认设定写入正文段落。
- 未确认设定必须标注“草案”“待定”“需用户确认”。
- 所有领域能力统一不设置能力代价；强度依靠触发条件、范围、持续时间、冷却、权限上限和目标抵抗控制。
- 不要一次性把所有脑洞塞进一个文档。
- 每次新增设定后，同步更新 `99-待定问题与决策记录.md`。
- 第一卷动态变化只写入 `../第一卷/`，不要复制回全书专题文档。
- 发生B级或C级变更时，严格执行 `98-AI设定变更协议与日志.md`。
- 开始写正文前，至少需要确认：第一卷边界、四人小队、首个副本、前10章功能和文风规范。
