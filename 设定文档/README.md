# 《群梦余生》设定文档目录说明

本目录是本小说项目的全书设定中枢，负责稳定世界规则、管理员、能力、角色底色、现实势力和全书阴谋。`../第一卷/` 是第一卷创作执行层，负责本卷边界、人物动态、案件副本和连续性。根目录《小说项目交接文档.md》保留为历史交接与讨论归档，不再作为持续更新的权威设定源。

> **C级重构冻结通知：** 2026-08-15起，旧版虚拟世界、管理员、领域、代行者、神降、神位、领域公司与旧终局全部冻结。当前迁移状态、已确认新蓝本、废弃范围和待决问题统一见 `97-C级重构事务-20260815.md`。未标记“迁移完成”的专题文档只能用于历史对照，不得继续扩写或进入第一卷。

发生冲突时，按以下优先级处理：

1. 已发布正文中的明确事实。
2. 本目录对应专题文档中的已确认设定。
3. `99-待定问题与决策记录.md` 中的已确认决策。
4. `../第一卷/` 中的本卷执行安排。
5. 工作草案、待确认方案和历史交接档。

若已发布正文与权威设定冲突，不得直接覆盖，必须按 `98-AI设定变更协议与日志.md` 处理。

## 家里电脑 Codex 接入顺序

新的 Codex/agent 接手全书设定任务时，请按顺序读取：

1. `设定文档/README.md`
2. `设定文档/97-C级重构事务-20260815.md`
3. `设定文档/99-待定问题与决策记录.md`
4. 讨论新版异能时，读取 `设定文档/02-异能与侵蚀体系.md`；`96-旧能力核心概念审计.md` 只保留概念提炼过程。
5. 只读取已经完成迁移的对应专题文档；迁移完成前不要按旧版 `00` 至 `06` 继续设计。
6. 根据任务读取对应文档：
   - 讨论世界观：读 `01-世界观圣经.md`
   - 讨论异能类型、个人表现、限制与成长：读 `02-异能与侵蚀体系.md`
   - 讨论最早受试者：前期只读 `01` 和 `97` 中已确认的远端功能；旧 `02-管理员档案.md` 仅供历史对照
   - 讨论双男主、配角：读 `03-角色档案.md`
   - 讨论现实政府、异能社会和民间势力：读 `04-现实势力与异能社会.md`
   - 讨论事故阴谋与终局：旧 `05-阴谋与事故线.md` 尚未迁移，只能用于影响扫描
   - 讨论中后期最早进入者关系与双世界战争：等待旧 `06` 完成迁移
7. 第一卷当前冻结；解除冻结后再转读 `../第一卷/README.md`
8. 只有追溯历史讨论时，才读取根目录 `小说项目交接文档.md`

## 第一卷创作接入顺序

讨论第一卷总纲、副本或章节时，优先读取：

1. `../第一卷/README.md`

## 后续维护原则

- 已确认设定写入正文段落。
- 未确认设定必须标注“草案”“待定”“需用户确认”。
- 所有领域能力统一不设置能力代价；强度依靠触发条件、范围、持续时间、冷却、权限上限和目标抵抗控制。
- 不要一次性把所有脑洞塞进一个文档。
- 每次新增设定后，同步更新 `99-待定问题与决策记录.md`。
- 第一卷动态变化只写入 `../第一卷/`，不要复制回全书专题文档。
- 发生B级或C级变更时，严格执行 `98-AI设定变更协议与日志.md`。
- 开始写正文前，至少需要确认：第一卷边界、四人小队、首个副本、前10章功能和文风规范。
