# 设定文档目录说明

本目录是本小说项目的正式设定中枢。根目录下的《小说项目交接文档.md》保留为会议纪要和历史记录；本目录用于后续持续维护、让 AI 写作时按需读取。

## 家里电脑 Codex 接入顺序

新的 Codex/agent 接手时，请按顺序读取：

1. `设定文档/README.md`
2. `设定文档/00-项目总览.md`
3. `设定文档/99-待定问题与决策记录.md`
4. 根据任务读取对应文档：
   - 讨论世界观：读 `01-世界观圣经.md`
   - 讨论管理员和能力：读 `02-管理员与能力体系.md`
   - 讨论双男主、配角：读 `03-角色档案.md`
   - 讨论现实势力：读 `04-现实势力.md`
5. 如需完整上下文，再读根目录的 `小说项目交接文档.md`

当前只是轻量拆分，不是最终作品圣经定稿。

- 已经迁入：项目目标、基础类型、双男主人设、世界观起源、虚拟世界机制、现实势力线、能力体系方向。
- 明确未定：12 位管理员、第一位管理员、12 种能力、能力代价、副男主势力、第一男配势力、第一卷副本。

## 后续维护原则

- 已确认设定写入正文段落。
- 未确认设定必须标注“草案”“待定”“需用户确认”。
- 不要一次性把所有脑洞塞进一个文档。
- 每次新增设定后，同步更新 `99-待定问题与决策记录.md`。
- 开始写正文前，至少需要稳定：世界观圣经、管理员与能力体系、角色档案、第一卷副本库、文风规范。
