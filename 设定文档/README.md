# 《群梦余生》设定文档索引

本目录是全书唯一权威设定层。同一事实只在一个专题文档中定义，分卷与正文只保留执行摘要和链接。

## 权威顺序

1. 已发布正文中的明确事实。
2. 对应专题权威文档中的已确认设定。
3. `99-交接与待处理文档.md` 中的当前决策。
4. 分卷执行文档中的本卷安排。
5. 工作草案和讨论候选。

正文尚未发布时，可以直接重构现行设定；正文发布后不得静默覆盖读者已经看到的事实。

## 当前文档

- `00-项目总览.md`：项目定位、核心卖点、叙事原则与当前阶段。
- `01-世界观圣经.md`：恶意实验、首次融合事故、异世界融合集体阴影、超自然事件与事域、杀人规律与卡死、收容与唤醒重现、觉醒规则、侵蚀及终局硬边界。
- `02-异能与侵蚀体系.md`：四大类、十二觉醒类型、能力方向、成长与限制。
- `03-主舞台城市与角色基线.md`：湾城、十一区、双男主身份与关系起点。
- `04-现实势力与异能社会.md`：官方认知、登记政策与现实五股主要力量。
- `05-全书主线与终局.md`：已确认的主线边界与后续待设计内容。
- `97-重构待办.md`：当前仍未完成的迁移与创作任务。
- `99-交接与待处理文档.md`：项目交接入口、重大变更记录、决策索引与待确认清单。

## 任务读取范围

- 世界规则：读 `01`。
- 异能与个人能力：读 `02`。
- 城市、双男主与人物：读 `03`。
- 官方、商业、收容产业、老手及地下势力：读 `04`。
- 全书反派、实验真相与终局：读 `05` 和 `99`。
- 第一卷：先读 `../第一卷/README.md` 与 `../第一卷/00-第一卷总纲.md`，再按任务读取 `模块01` 至 `模块08`。

## 维护原则

- 不在活动目录保存旧版设定副本，历史只通过 Git 追溯。
- 不按能力类型自动创建势力、人物或命定阵营。
- 不为暂时不会进入剧情的制度、人物和终局细节无限扩写。
- B级或C级变更必须同步权威文档、决策记录和执行层。
- 每次批量修改后扫描旧术语、失效链接与因果冲突，并运行 `git diff --check`。
