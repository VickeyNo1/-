# 设定文档目录说明

本目录是本小说项目的正式设定中枢。根目录下的《小说项目交接文档.md》是持续更新的跨 AI 接入指南与进度快照；具体设定发生冲突时，以本目录对应专题文档和 `99-待定问题与决策记录.md` 为准。

## 家里电脑 Codex 接入顺序

新的 Codex/agent 接手时，请按顺序读取：

1. `设定文档/README.md`
2. `设定文档/00-项目总览.md`
3. `设定文档/99-待定问题与决策记录.md`
4. 根据任务读取对应文档：
   - 讨论世界观：读 `01-世界观圣经.md`
   - 讨论领域技能、限制、成长和代行者质变：读 `02-领域与能力体系.md`
   - 讨论管理员背景、立场、关系、记忆考验和神降：读 `02-管理员档案.md`
   - 完整设计某位管理员及其领域：两份 `02` 文档一起读
   - 讨论双男主、配角：读 `03-角色档案.md`
   - 讨论现实势力：读 `04-现实势力.md`
   - 讨论事故阴谋、三位特别管理员立场与终局：读 `05-阴谋与事故线.md`
5. 如需完整上下文，再读根目录的 `小说项目交接文档.md`

## 后续维护原则

- 已确认设定写入正文段落。
- 未确认设定必须标注“草案”“待定”“需用户确认”。
- 所有领域能力统一不设置能力代价；强度依靠触发条件、范围、持续时间、冷却、权限上限和目标抵抗控制。
- 不要一次性把所有脑洞塞进一个文档。
- 每次新增设定后，同步更新 `99-待定问题与决策记录.md`。
- 开始写正文前，至少需要稳定：世界观圣经、领域与能力体系、管理员档案、角色档案、第一卷副本库、文风规范。
