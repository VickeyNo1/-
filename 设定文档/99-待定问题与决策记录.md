# 99-待定问题与决策记录

本文件是现行决策索引，不重复保存专题全文。详细规则以 `01` 至 `05` 的对应权威文档为准。

## 当前已确认

### 世界与副本

- 异世界是真实存在、没有天然个体边界的精神连续体，不是虚拟空间、游戏或AI模拟。
- 恶意人体实验使异世界获得现实坐标；最早进入者的回归呼唤与多元宇宙自然规律共同推动侵蚀。
- 通道是能量共鸣，最后一卷以前不能运输现实物质。首次共鸣会留下标记，能力与武器使用越频繁，再次被捕获的概率越高。
- 副本调用人类集体潜意识中的恐怖原型，并与当次参与者的私人材料拼接。
- 每个灵异反派拥有本场独立的触发条件和杀人规律。杀人规律决定如何活下来，核心规律被破解后副本直接结束。
- 贡献指直接发现、利用或破坏副本核心规律。返回、成长和获得晶体均不是自动结算。
- 官方不能进入副本救人，也不能强制唤醒被捕获者；破坏意识与身体的连接只会导致死亡。

### 异能与晶体

- 异能分为意识类、现实类、身体类和规则类，共十二种觉醒类型；每个人原则上只有一种类型。
- 四类潜力顺序为规则类高于现实类，现实类高于意识类，意识类高于身体类。
- 规则类是极少数人的先天异常，即使没有实验和异世界侵蚀也可能自主觉醒；其他三类主要由通道经历与返回适应塑成。
- 规则类在精神崩溃、能力失控或掌握不完整时可能向周围散出力量，大幅提高附近人员被捕获的概率，但不能创造通道、指定对象、选择副本或保证固定组队。
- 世界内不存在客观支点或统一等级。六十项清单只作为作者约束能力边界的方向表。
- 程序、概率和系统按各自六项顺序发展；其余九种类型随机出现新能力或直接增强已有能力。
- 成长不要求创伤。现实使用与副本贡献可能使能力变强，通用消耗只有疲劳。
- 晶体赋能武器后可以长期使用。普通人可以使用低级武器，中级武器可能致死，高级武器仅接触便可能致死。
- 普通人使用异能武器也会加强共鸣，被异世界视为具有潜力并提高进入副本的概率。

### 现实与人物

- 故事发生在虚构的大湾区式超大城市“湾城”，下设十一区。
- 主角故事开始前，政府已经成立异能者特别行动力量和军队异能分部；异能现象半公开，异世界真相保密。
- 现实异能社会由官方体系、商业机构、晶体产业、副本老手网络、地下市场与犯罪网络五股力量构成。幸存者与家属的互助活动缺乏统一组织、稳定资源和足够影响力，不计入主要势力。
- 主要异能者反派适合隐藏在商业机构、副本老手网络与晶体产业的交叉处，但现实组织不能控制通道或安排固定副本队伍。
- 主男主是软件工程大四学生，先天具有规则类程序潜质，首次副本返回后显现 `IF`，依次发展 `IF → AND → OR → NOT → LOOP → DEF`。
- 副男主是刑侦专业警校应届毕业生，首次副本后觉醒适应强化，最先表现为周期性局部代偿。
- 副男主父亲死于疑似副本老手围杀，该案贯穿多卷，不作为普通地下利益链案件处理。

### 第一卷

- 主男主开篇第一次进入副本，随机遇见已经完成登记并进入官方体系的副男主；返回后显现规则类程序方向 `IF`，并先以临时保密协作、特殊线人或同等身份参与案件。
- 第一卷核心功能是让主男主从认为异常只是短期插曲，走到确认自己无法置身事外并正式加入官方组织；双男主从副本合作走到正式搭档。
- 第一卷核心案是体制内叛徒科学家盗取政府研究成果，通过恒川智能为企业和家族非法筛选未成年异能者。
- 恒川明面经营深度睡眠舱、睡眠腕带和健康数据平台，实际接收买家送来的受试者，运行实验、收集数据并协助处理失败者现实身体。
- 私人实验只能提高被副本捕获和受训者生还的概率，不能指定副本、固定组队、保证觉醒或选择能力类型。
- 叛徒科学家意外发现主男主属于规则类，利用其尚未正式加入组织、保护不足的窗口将其抓入地下实验室，以折磨、药物和设备刺激诱发崩溃，试图验证规则力量外溢能否放大批量捕获。第三次副本由失控共鸣间接引发，不是科学家控制通道。
- 第一卷分六部分，安排三次副本：开篇双男主相遇、主男主独自遇见蓝腕带少年、地下实验室高潮副本。
- 蓝腕带少年参加后两次副本，第三次返回后显现规则类概率方向第一项“采样”；卷末先作为未成年受害者和保护对象，不立即成为一线调查员。
- 蓝腕带少年是后续重要配角；第一卷同时出现两名规则类属于需要承担长期剧情价值的重大事件，不能把少年的稀有能力用完即弃。
- 第一卷实验案直接实施者落网。父亲案势力不参与本卷，只在结案复盘中通过一条历史交易或证物痕迹勾出下一卷。
- 主男主正式加入官方首先为了训练、自保、失控管理及保护家人，其次源于对黑暗势力的恐惧和厌恶；信任官方与帮助副男主是较后动机，不得写成突然产生献身使命。

## 明确不采用

- 管理员、固定领域、等级晋升、代行者、神降、神位、从神和领域公司。
- 最早进入者的回归派、断路派或其他内部阵营战争。
- 事故后知情者争夺实验遗产，以及现实组织开发、经营或制造通道。
- 创伤产生力量、系统评分、固定技能奖励和每场副本必掉晶体。
- 无剧情用途的完整官方行政、医疗、移交和证据流程。
