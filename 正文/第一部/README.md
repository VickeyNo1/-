# 第一部正文目录

本目录用于保存第一部实际章节。正文开始前先确认 `../../第一部/00-第一部总纲.md`、当前故事单元和主要人物状态。

## 建议命名

- `第001章-暂名.md`
- `第002章-暂名.md`

章名未确认时可以暂名，章节编号必须固定为三位数，便于排序和批量检查。

## 每章工作流

1. 写作前读取第一部总纲、当前副本、人物轨迹和连续性台账。
2. 初稿完成后检查视角、人物动机、能力边界、信息揭露和章末推动力。
3. 用户确认章节后，把状态从草稿改为定稿；实际上传起点后标记为已发布。
4. 同步更新 `../../第一部/03-线索伏笔与连续性台账.md`。

章节正文只呈现角色当时能够感知和理解的事实，不直接引用作者层世界观说明。
