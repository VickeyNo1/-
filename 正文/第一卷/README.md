## 每章工作流

1. 写作前读取第一卷总纲、当前副本、人物轨迹和连续性台账。
2. 初稿完成后检查视角、人物动机、能力边界、信息揭露和章末推动力。
3. 用户确认章节后，把状态从草稿改为定稿；实际上传起点后标记为已发布。
4. 同步更新 `../../第一卷/03-线索伏笔与连续性台账.md`。
