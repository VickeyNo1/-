# 小说项目入口

本项目采用“全书设定层、分部执行层、正文章节层”三层结构，目的是让AI在写作时只读取当前任务真正需要的上下文，同时保持全书设定只有一个权威来源。

## 目录

- `设定文档/`：全书世界观、管理员、能力、人物底色、现实势力、阴谋和决策索引。
- `第一部/`：第一部总纲、人物动态、案件副本链和连续性台账。
- `正文/第一部/`：第一部实际章节。
- `小说项目交接文档.md`：早期讨论与交接历史，仅供追溯，不作为当前权威来源。

## 新AI接入

1. 先读 `设定文档/README.md`。
2. 再读 `设定文档/99-待定问题与决策记录.md`。
3. 第一部任务转读 `第一部/README.md`。
4. 只根据任务回查对应专题文档，不默认读取全部文件。

## 整体设定变更

发生影响多个文档、人物、能力、副本或已发布章节的变更时，执行 `设定文档/98-AI设定变更协议与日志.md`：先分析影响，等待用户确认，再修改权威定义、执行文档、连续性台账和受影响正文。
