# 《群梦余生》项目入口

正式书名：**《群梦余生》**。

> **C级重构进行中：** 项目已于2026-08-15冻结旧版“虚拟世界、管理员、领域、代行者与神位”体系，正在迁移到“恶意人体实验、无边界精神异世界、噩梦通道与现实侵蚀”的新蓝本。接手任何设定或第一卷任务前，必须先读 `设定文档/97-C级重构事务-20260815.md`；尚未迁移的旧专题文档不得作为新内容继续扩写。

本项目采用“全书设定层、分卷执行层、正文章节层”三层结构，目的是让AI在写作时只读取当前任务真正需要的上下文，同时保持全书设定只有一个权威来源。

## 目录

- `设定文档/`：全书世界观、异能、人物底色、现实势力、阴谋和决策索引。
- `第一卷/`：第一卷总纲、人物动态、案件副本链和连续性台账。
- `正文/第一卷/`：第一卷实际章节。
- `小说项目交接文档.md`：早期讨论与交接历史，仅供追溯，不作为当前权威来源。

## 新AI接入

1. 先读 `设定文档/README.md`。
2. 当前重构期间再读 `设定文档/97-C级重构事务-20260815.md`。
3. 再读 `设定文档/99-待定问题与决策记录.md`。
4. 世界观任务读 `设定文档/01-世界观圣经.md`，异能任务读 `设定文档/02-异能与侵蚀体系.md`，现实势力任务读 `设定文档/04-现实势力与异能社会.md`。
5. 第一卷任务目前处于冻结状态；解除冻结后再转读 `第一卷/README.md`。
6. 只根据任务回查已经完成迁移的专题文档，不默认读取全部文件。

## 整体设定变更

发生影响多个文档、人物、能力、副本或已发布章节的变更时，执行 `设定文档/98-AI设定变更协议与日志.md`：先分析影响，等待用户确认，再修改权威定义、执行文档、连续性台账和受影响正文。
