# 《群梦余生》项目入口

正式书名：**《群梦余生》**。

本项目是双男主、异能、规则恐怖与现实调查结合的男频长篇小说。当前正文尚未开始，世界底座、异能体系、主舞台、双男主基线、现实势力结构和第一卷卷级大纲已经建立；第一卷副本、人物与章节结构正在逐项设计。

## 目录

- `设定文档/`：全书唯一权威设定层。
- `第一卷/`：第一卷执行层，卷级大纲已经建立。
- `正文/第一卷/`：第一卷正文目录，目前为空。
- `小说项目交接文档.md`：当前项目交接摘要。

## 接入顺序

1. 读取 `设定文档/README.md`。
2. 读取 `设定文档/00-项目总览.md`。
3. 读取 `设定文档/99-待定问题与决策记录.md`。
4. 根据任务读取 `01` 至 `05` 中对应的现行专题文档。
5. 处理第一卷时再读取 `第一卷/README.md`。
