# 《群梦余生》项目入口

正式书名：**《群梦余生》**。

本项目是双男主、异能、规则恐怖与现实调查结合的男频长篇小说。当前正文尚未开始，世界底座、异能体系、主舞台、双男主基线、现实势力结构和第一卷卷级大纲已经建立；第一卷超自然事件、人物与章节结构正在逐项设计。

## 目录

- `设定文档/`：全书唯一权威设定层。
- `第一卷/`：第一卷执行层，重新设计中。
- `正文/第一卷/`：第一卷正文目录，目前为空。
- `素材参考/`：创作参考素材（外部案例调研），**不是设定**，无权威效力。

## 接入顺序

1. 读取 `设定文档/README.md`。
2. 读取 `设定文档/00-项目总览.md`。
3. 读取 `设定文档/99-交接与待处理文档.md`。
4. 根据任务读取 `01` 至 `05` 中对应的现行专题文档。
5. 处理第一卷时再读取 `第一卷/README.md`。

## 历史版本

活动目录不保留旧版设定副本。重构前完整版本由 Git 标签 `pre-worldview-reboot-20260815` 与仓库提交历史保存，旧版管理员、领域、代行者、神降、神位和旧第一卷方案均不属于现行设定。2026-08-16 起副本模式整体删除，改为超自然事件模式，相关旧设定（副本、通道、捕获、返回机制）同样只通过 Git 历史追溯。
